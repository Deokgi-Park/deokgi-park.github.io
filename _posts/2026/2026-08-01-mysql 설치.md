# WSL Ubuntu에서 MySQL 설치와 기본 사용법

Windows에서 MySQL을 사용할 때는 Windows용 설치 관리자를 쓰는 방법도 있지만, WSL 환경에서 백엔드 개발을 한다면 Ubuntu에 설치해 CLI로 사용하는 편이 편리하다. 이 글은 WSL Ubuntu에 MySQL Server를 설치하고, 개발용 계정과 데이터베이스를 만든 뒤 조회하는 과정까지 정리한다.

## 설치 환경

- Windows 11 + WSL 2
- Ubuntu 18.04
- MySQL Community Server 5.7

배포판과 시점에 따라 설치되는 MySQL 버전은 달라질 수 있다. 아래 명령으로 실제 버전을 확인한다.

```bash
mysql --version
```

## MySQL 설치

WSL Ubuntu 터미널을 열고 패키지 목록을 갱신한 뒤 MySQL Server를 설치한다.

```bash
sudo apt update
sudo apt install mysql-server
```

설치 후 서비스 상태를 확인한다.

```bash
sudo service mysql status
```

`active (running)`이 보이면 정상적으로 실행 중이다. 서비스가 멈춰 있다면 다음 명령으로 시작한다.

```bash
sudo service mysql start
```

## root로 접속하기

Ubuntu 패키지로 설치한 MySQL은 `root` 계정을 운영체제의 sudo 권한과 연결해 두는 경우가 많다. 따라서 다음 명령으로 관리자 콘솔에 접속한다.

```bash
sudo mysql
```

접속에 성공하면 `mysql>` 프롬프트가 표시된다.

```sql
SELECT VERSION();
```

## 개발용 사용자와 데이터베이스 만들기

애플리케이션에서는 `root` 계정 대신 별도 계정을 사용한다. 아래 예시는 `loverdeok` 사용자와 `myblog` 데이터베이스를 생성하고, 해당 DB에만 모든 권한을 부여한다.

```sql
CREATE DATABASE myblog
  CHARACTER SET utf8mb4
  COLLATE utf8mb4_unicode_ci;

CREATE USER 'loverdeok'@'localhost' IDENTIFIED BY '강력한_비밀번호';

GRANT ALL PRIVILEGES ON myblog.* TO 'loverdeok'@'localhost';
FLUSH PRIVILEGES;
```

`강력한_비밀번호`는 실제 비밀번호로 바꾼다. 비밀번호는 Git 저장소, 게시물, 소스 코드에 직접 넣지 않는다.

계정 생성 결과를 확인한다.

```sql
SELECT user, host FROM mysql.user WHERE user = 'loverdeok';
EXIT;
```

## 일반 사용자로 접속하기

새 계정으로 접속할 때는 `-p` 옵션을 반드시 붙인다.

```bash
mysql -u loverdeok -p
```

비밀번호 입력 중에는 터미널에 글자가 표시되지 않는 것이 정상이다. 특정 DB를 바로 선택해 접속할 수도 있다.

```bash
mysql -u loverdeok -p myblog
```

## 데이터베이스 조회와 선택

MySQL 콘솔에서 데이터베이스 목록을 확인하고 사용할 DB를 선택한다.

```sql
-- 데이터베이스 목록 조회
SHOW DATABASES;

-- 데이터베이스 선택
USE myblog;

-- 현재 선택된 데이터베이스 확인
SELECT DATABASE();

-- 선택한 DB의 테이블 목록 조회
SHOW TABLES;
```

테이블이 생성된 뒤에는 구조와 데이터를 다음처럼 확인한다.

```sql
DESCRIBE 테이블명;
SHOW CREATE TABLE 테이블명;
SELECT * FROM 테이블명 LIMIT 10;
```

## ERROR 1045: Access denied 해결

다음 오류는 사용자 이름은 전달됐지만 비밀번호가 전달되지 않았다는 뜻이다.

```text
ERROR 1045 (28000): Access denied for user 'loverdeok'@'localhost' (using password: NO)
```

원인은 보통 `mysql -u loverdeok`처럼 `-p` 옵션을 생략한 경우다. 아래 명령으로 다시 접속한다.

```bash
mysql -u loverdeok -p
```

`using password: YES`로 바뀌었는데도 접속하지 못한다면, 비밀번호가 틀렸거나 `loverdeok@localhost` 계정에 필요한 권한이 없는 상황이다. root로 접속해 비밀번호와 권한을 다시 설정한다.

```bash
sudo mysql
```

```sql
ALTER USER 'loverdeok'@'localhost' IDENTIFIED BY '새로운_강한_비밀번호';
GRANT ALL PRIVILEGES ON myblog.* TO 'loverdeok'@'localhost';
FLUSH PRIVILEGES;
```

## Windows에 직접 설치하는 경우

WSL 대신 Windows에서 MySQL을 직접 설치하려면 [MySQL Downloads](https://www.mysql.com/downloads/)에서 Windows용 설치 관리자를 내려받아 설치한다.

![MySQL Downloads 페이지](/assets/images/posts/2026-08-01-mysql 설치/01.png)

설치 과정에서는 root 비밀번호를 안전하게 보관하고, 서버 포트는 기본값인 `3306`을 사용하면 된다.

![Windows용 MySQL 설치 파일 선택](/assets/images/posts/2026-08-01-mysql 설치/02.png)

WSL MySQL과 Windows MySQL을 동시에 실행하면 같은 `3306` 포트를 두 서버가 사용할 수 없으므로, 한 환경만 사용하거나 포트를 다르게 설정한다.

## 마무리

개발 환경에서는 `root` 대신 DB별 최소 권한을 가진 사용자로 접속한다. 설치 후에는 서비스 상태, 계정 접속, `USE 데이터베이스명`, 테이블 조회까지 확인하면 기본 구성이 완료된다.
