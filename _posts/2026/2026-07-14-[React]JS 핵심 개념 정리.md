# 안내
> 리액트 강의를 듣고 기록한 내용입니다. 본격적인 리액트 강의에 앞서 배운 기본적인 javascript 이외의 여러 특성을 정리해보았습니다.

## class와 constructor

자바의 클래스처럼 자바스크립트의 class도 객체를 찍어내는 **청사진** 역할을 한다.<br/><br/>
`constructor`는 `new`로 인스턴스를 생성할 때 전달받은 매개변수로 인스턴스 필드를 초기화하는 특수 메소드다.

```js
class Person {
  constructor(name, age) {
    this.name = name;
    this.age = age;
  }

  greet() {
    console.log(`안녕하세요, ${this.name}입니다.`);
  }
}

const p = new Person('러버덕', 30);
p.greet(); 
// 안녕하세요, 러버덕입니다.
```
---

## class는 청사진, 상속(extends)도 가능

class는 "이런 모양의 객체를 만들겠다"는 설계도이며, 자바처럼 `extends`로 상속받아 기능을 확장할 수 있다.

```js
class Student extends Person {
  constructor(name, age, school) {
    super(name, age);
    this.school = school;
  }
}
```

## 객체에서의 function 사용

객체에서도 `함수명() {}` 형태로 함수를 저장해서 사용할 수 있다.

```js
const person = {
  name: '러버덕',
  greet() {
    console.log(`안녕하세요, ${this.name}입니다.`);
  },
};

person.greet();
// 안녕하세요, 러버덕입니다.
```

## 구조 분해 할당(디스트럭처링)

배열과 객체의 각 값을 매칭되는 변수에 바로 꺼내 담는 문법  
객체의 구조분해 할당의 경우 객체의 key와 변수의 명칭이 같아야 한다.

```javascript
// 배열 구조 분해
 const [first, second] = [1, 2];
 console.log(first, second)
 //1 2

// 객체 구조 분해
const { name, age } = { name: '러버덕', age: 30 };
 console.log(name, age)
 //러버덕 30
```
---

## 구조 분해 할당 시 별칭과 초기값
구조 분해 할당 시 객체의 key와 변수의 명칭이 같아야하나 별칭을 통해 다른 변수명으로 사용가능  
매칭되는 key 값이 없는 경우 초기값을 셋팅 가능
```javascript
// 객체 구조 분해 별칭(rename) 예시 — key와 변수명이 달라도 됨
// 객체 구조 분해 기초값 예시 — 매칭되는 값이 없을 경우 할당되는 기본값을 지정할 수 있다
const { name: userName, age = 20 } = { name: '러버덕' };
console.log(userName, age);
// 러버덕 20

// 초기값이 적용되는 경우는 undefined 일때만 임을 숙지
const { age = 20 } = { age: null };
console.log(age); 
// null (20이 아님)
```

## 스프레드 연산자(...)

배열이나 객체를 펼쳐서 복사하거나 합칠 때 사용한다.

```js
const arr1 = [1, 2, 3];
const arr2 = [...arr1, 4, 5];
console.log(arr2)
// [1, 2, 3, 4, 5]

const obj1 = { a: 1, b: 2 };
const obj2 = { ...obj1, c: 3 };

console.log(obj2)
// {a: 1, b: 2, c: 3}
```

## 함수는 일급 객체(First-Class Function)

자바스크립트의 함수는 다음 조건을 만족하므로 일급 객체다.

1. 변수에 저장할 수 있다.
2. 함수의 인자로 전달할 수 있다.
3. 함수의 반환값으로 사용할 수 있다.
4. 자료구조나 객체의 프로퍼티에 저장할 수 있다.

```js
const add = (a, b) => a + b; // 1. 변수에 저장

function applyOp(a, b, op) { // 2. 인자로 전달
  return op(a, b);
}

function makeAdder(a) { // 3. 반환값으로 사용
  return (b) => a + b;
}

const utils = { add }; // 4. 객체 프로퍼티에 저장
```

## Call by Value vs Call by Reference

객체와 배열은 **레퍼런스 of 벨류**, 즉 메모리 주소가 값으로 전달되는 방식으로 동작한다.  

그 외 기본형(number, string, boolean 등)은 값 자체가 복사되어 전달된다.

| 구분 | 종류 | 동작 방식 |
|:---:|:---:|:---:|
|  기본형  | number, string, boolean 등 | 메모리 주소가 아닌 값 자체를 변경 |
|  참조형  | 객체, 배열 | 메모리 주소는 고정, 주소의 내부 값을 변경 |

`const`로 선언한 객체나 배열의 값을 변경할 수 있는 이유도 여기 있다. `const`가 막는 것은 **새로운 값(주소)으로 덮어쓰는 재할당**이고, 기존 주소가 가리키는 객체 내부를 메소드로 수정하는 것은 재할당이 아니므로 가능하다.

```js
const obj = { count: 0 };
obj.count = 1; // 가능 (재할당이 아님)
// obj = {}; // 불가능 (재할당이라 에러)

const arr = [1, 2, 3];
arr.push(4); // 가능
// arr = [1, 2, 3, 4]; // 불가능
```

## 배열을 다루는 화살표 함수: slice, concat, reduce, filter, findIndex, find, map

```js
const nums = [1, 2, 3, 4, 5];

nums.slice(1, 3);           // [2, 3] 원본 변경 없이 일부 추출
nums.concat([6, 7]);        // [1,2,3,4,5,6,7] 원본 변경 없이 배열 합치기
nums.filter((n) => n % 2 === 0); // [2, 4] 조건에 맞는 요소만
nums.find((n) => n > 3);    // 4, 조건에 맞는 첫 요소
nums.findIndex((n) => n > 3); // 3, 조건에 맞는 첫 요소의 인덱스
nums.map((n) => n * 2);     // [2,4,6,8,10]
nums.reduce((acc, cur) => acc + cur, 0); // 15, 누적 계산
```

공통점은 모두 **원본 배열을 변경하지 않고 새로운 값을 반환**한다는 것. 리액트에서 상태를 불변으로 다뤄야 하는 이유와 바로 연결되는 부분이라 특히 신경 써서 봐야 한다.
